# Platform icons

Instagram, Facebook, TikTok, X, YouTube, Pinterest, Snapchat, Threads and WhatsApp, copied unchanged from
Simple Icons 16.35.0 (npm `simple-icons`, `icons/<slug>.svg`), fetched 2026-10-15. Simple Icons is released
under CC0 1.0 (public domain dedication). The marks themselves stay their owners' trademarks; the ads use them
only to point at the brand's own accounts.

Simple Icons no longer ships LinkedIn, so `app/ads/icons.py` draws a plain "in" tile for it instead.
